# JWT Inspector

A tiny, dependency-free JWT decoder that runs entirely in the browser.

## Features
- Decode JWT header and payload
- View the raw signature segment
- Handles base64url correctly
- No backend, dependencies, login, or network request

## Security
This tool **does not verify signatures**. Decoding a JWT is not the same as validating it. Never paste sensitive production tokens into websites you do not trust.

## Run
Open `index.html` directly in a browser.
